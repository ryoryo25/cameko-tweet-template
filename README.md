# 📸 カメコツイートジェネレータ

≠ME（ノットイコールミー）・≒JOY（ニアリーイコールジョイ）のライブ写真投稿用ツイートを簡単に作成できるWebアプリです。

🔗 **https://ryoryo25.github.io/cameko-tweet-template/**

## 機能

- コメント・日付・ライブ名・会場名を入力して定型ツイートを生成
- ≠ME / ≒JOY のメンバーをチェックボックスで選択
- 選択したグループに応じて `#ノイミー_カメコ` / `#ニアジョイ_カメコ` を自動付与
- リアルタイムプレビュー＆ワンクリックコピー
- 文字数カウント表示

## 出力例

```
最高でした！

2026.07.27
≠ME 7th ANNIVERSARY PREMIUM CONCERT
東京ガーデンシアター

#櫻井もも
#本田珠由記
#ノイミー_カメコ
```

## 技術構成

- HTML / CSS / JavaScript（フレームワークなし）
- GitHub Pages でホスティング
- GitHub Actions で自動デプロイ（`main` push時）
